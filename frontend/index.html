SOBRE O SISTEMA

Mais organização para o campus.

Uma proposta digital para solicitações e controle de saída de estudantes.

Solicitação digital

Alunos e responsáveis informam os dados necessários, o motivo e recebem um protocolo.

Análise de gestão

Usuários autorizados revisam as informações e registram deferimento ou indeferimento.

Dupla checagem

Recepção e portaria confirmam etapas diferentes, com usuário e horário registrados.

Pronto para integração

O frontend usa dados demonstrativos salvos no navegador. Para produção, conecte à API e ao banco de dados, valide tudo no servidor, aplique autenticação real e registre trilha de auditoria.
